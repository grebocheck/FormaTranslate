# Однофайлова збірка

На Windows у каталозі проєкту:

Спочатку підготуйте повний комплект OCR, моделей, Tesseract і BabelDOC та перевірте його за [WINDOWS-RUNTIME.md](WINDOWS-RUNTIME.md). Типова збірка вимагає цей комплект; `--desktop-only` створює окремо названий варіант лише для розробки.

```powershell
uv sync --group build
uv run --group build python scripts/build.py
```

Результат для 64-бітної Windows: `dist/Forma-windows-x86_64.exe`. Користувачеві достатньо цього файла для запуску Forma: Python, папка `_internal` і `.env` не потрібні. Адреса API, модель і ключ задаються в налаштуваннях застосунку. Налаштування зберігаються в профілі користувача, ключ — у системному сховищі облікових даних, якщо воно доступне.

Та сама команда на Linux створює `dist/Forma-linux-x86_64` (або файл із відповідною архітектурою). Вона не змінює попередню папку `dist/Forma` чи старі архіви.

Скрипт включає Python, бібліотеки застосунку та QML. Повна Windows-збірка також вбудовує OCR із локальними моделями, Tesseract і BabelDOC з ресурсами. Встановлювати їх окремо користувачеві не потрібно. Файли `.env`, ключі, особисті налаштування, документи й результати перекладів у збірку не потрапляють. На Linux зберігається схема з окремо встановленими рушіями.

PyInstaller створює файл для ОС та архітектури Python, яким його запущено. Перевірену Windows-збірку слід створювати й випробовувати у Windows. Збірка Windows через Windows Python у Wine придатна для попередніх випробувань, але потребує окремої перевірки нативних діалогів і сховища ключів у Windows. CI/CD не використовується. [Документація PyInstaller](https://pyinstaller.org/en/stable/operating-mode.html).

Під час запуску однофайловий застосунок розпаковує бібліотеки в тимчасову папку ОС; тому старт може тривати довше, ніж у попередньої збірки з папкою залежностей. [Робота one-file mode](https://pyinstaller.org/en/stable/operating-mode.html#how-the-one-file-program-works).
