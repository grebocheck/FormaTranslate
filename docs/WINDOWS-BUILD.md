# Портативна збірка у ZIP

Для користувачів випускається одна повна Windows-версія з локальними моделями. Спочатку підготуйте комплект OCR, моделей, Tesseract і BabelDOC та перевірте його за [WINDOWS-RUNTIME.md](WINDOWS-RUNTIME.md). Типова збірка вимагає цей комплект; `--desktop-only` створює окремо названий варіант лише для розробки, який не публікується як користувацький пакунок.

```powershell
uv sync --locked --group build
uv run --group build python scripts/build.py
```

Результат для 64-бітної Windows — папка `dist/Forma-windows-x86_64/` із `Forma-windows-x86_64.exe` в корені та залежностями у `_internal`. Релізний ZIP містить усю цю структуру й ліцензійні матеріали. Користувач розпаковує **весь архів** у папку та запускає EXE з неї. Папку `_internal` та інші файли потрібно зберігати разом із EXE; переносити лише EXE не можна. Встановлювати Python або створювати `.env` не потрібно. Адреса API, модель і ключ задаються в налаштуваннях застосунку. Налаштування зберігаються в профілі користувача, ключ — у системному сховищі облікових даних, якщо воно доступне.

Встановлений ABBYY залишається додатковим варіантом OCR у налаштуваннях повної версії. Робота зі звичайним ABBYY проходить через його редактор і явний імпорт перевіреного DOCX; автоматичне збереження потребує відповідної ліцензії. Дивіться [налаштування ABBYY](ABBYY.md).

Та сама команда на Linux створює папку `dist/Forma-linux-x86_64/` (або з назвою відповідної архітектури), у корені якої міститься виконуваний файл `Forma-linux-x86_64`, а поруч — `_internal` із залежностями. Для запуску також потрібен увесь вміст архіву.

Скрипт включає Python, бібліотеки застосунку та QML у портативну папку PyInstaller onedir. Повна Windows-збірка також містить OCR із локальними моделями, Tesseract і BabelDOC з ресурсами. Встановлювати їх окремо користувачеві не потрібно. Файли `.env`, ключі, особисті налаштування, документи й результати перекладів у збірку не потрапляють. На Linux зберігається схема з окремо встановленими рушіями.

PyInstaller створює файл для ОС та архітектури Python, яким його запущено. Перевірену Windows-збірку слід створювати й випробовувати у Windows. Збірка Windows через Windows Python у Wine придатна для попередніх випробувань, але потребує окремої перевірки нативних діалогів і сховища ключів у Windows. CI/CD не використовується. [Документація PyInstaller](https://pyinstaller.org/en/stable/operating-mode.html).

Застосунок завантажує бібліотеки й рушії з уже розпакованої папки, тому під час кожного запуску не витрачає час і тимчасове місце на повторне розпакування великого EXE. Завантаження моделей і обробка документів усе одно потребують часу. Оновлення слід розпаковувати в нову папку, не змішуючи залежності різних версій.
