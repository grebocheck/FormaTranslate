# Translation instructions

Choose **Custom instructions** in the document sidebar, or **Instructions** in Text & photos. Enter reusable terminology, style and wording preferences, then save. For example:

> Use British English. Use APPENDICES for appendix headings. Keep a formal technical tone.

Instructions are saved locally and applied to subsequent document, text and photo translations, including editorial passes and PDF requests through BabelDOC. The current run keeps the instructions captured when it started. Clear the field and save to disable them. The limit is 8,000 characters.

The selected target language, document meaning, numbers, protected codes, formatting and output structure remain protected. An explicit glossary takes priority for exact terms. Instructions influence the model; they are not a guarantee of every linguistic choice.

Changing instructions invalidates reusable translation results for the next job. Reports retain the instructions used for that job, so manual review/export preserves its context. Existing results are not automatically rewritten. Instructions are ordinary local preference/report data, not secrets: do not put credentials in this field. They are sent to the selected provider with translation requests.

The interface is localized in Ukrainian, English, Polish and German. Switching interface language preserves the instruction draft exactly as typed.
