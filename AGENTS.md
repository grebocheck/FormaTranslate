# Project instructions

Use codebase-memory-mcp for code discovery before text search. Start with search_graph, trace_path and get_code_snippet; index this repository if it is not indexed. Use rg for literals, configuration files, or gaps in graph coverage.

The application is Python/PySide6, with QML under src/forma/ui. Python implementation is grouped into core, settings, persistence, accounting, localization, providers, translation, documents, memory and presentation packages; see docs/ARCHITECTURE.md. Keep Qt descriptors in the Backend facade and workflow implementations in focused presentation modules. API keys are entered in the application and optionally stored in the native OS credential vault; .env/environment variables remain a legacy input. Never print credentials, include them in reports/preferences JSON, or bundle .env/user data. Releases are single-file executables with no required .env sidecar.

Run uv run ruff check . and uv run pytest for substantive changes. PDF and OCR integration use isolated workers. Windows Standard uses installed ABBYY or external OCR/PDF engines; Complete packages include BabelDOC, OCR, models and Tesseract. Linux/source installations use separately installed workers. ABBYY detection does not imply Extended CLI licensing; ordinary editions use assisted manual DOCX export. Wine builds are explicitly named candidates and never imply native Windows validation. Paid API calls require a user-configured provider; offline tests must use a fake provider or local test server. Keep comparison metrics separate from linguistic quality judgments.

Public history starts from a sanitized snapshot. Never mirror private pre-publication branches or research data into the public repository. Releases are manual, with no CI/CD: follow docs/RELEASING.md and include the corresponding dependency source archives and license materials. src/forma/__init__.py is the single version source.

UI localization belongs at presentation boundaries. Never localize document contents, protocol values, persistent review fingerprints or canonical JSON reports. Maintain English, Ukrainian, Polish, German, French and Spanish catalogs and verify live theme/language switching without losing settings, selections or review edits. OCR source languages are separate from interface languages.
